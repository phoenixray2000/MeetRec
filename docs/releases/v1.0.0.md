# MeetRec 1.0.0

MeetRec 1.0.0 is the first versioned Windows tray recorder release.

## Highlights

- Independent post-processing switches for normalization/source leveling, speaker echo reduction, microphone denoising, and loopback ducking.
- Both-mode mixing now reduces microphone echo first, levels microphone and system audio from active audio segments, then ducks loopback audio while the microphone is active.
- RNNoise microphone denoising is available as an optional conservative 35% wet mix with latency compensation.
- Windows executable metadata now reports `FileVersion` `1.0.0.0` and `ProductVersion` `1.0.0`.

## Artifact

Download `MeetRec-1.0.0-win-x64.zip`, extract the folder, and run `MeetRec\MeetRec.exe`.
