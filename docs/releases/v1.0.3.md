# MeetRec 1.0.3

MeetRec 1.0.3 fixes packaged and auto-start configuration persistence.

## Highlights

- Settings now resolve to `%APPDATA%\MeetRec\settings.json` instead of depending on the current working directory.
- Manual launch, Windows Run-key auto-start, and packaged execution now share the same writable per-user settings file.
- Saving settings creates the config directory when it does not already exist.
- Windows executable metadata now reports `FileVersion` `1.0.3.0` and `ProductVersion` `1.0.3`.

## Artifact

Download `MeetRec-1.0.3-win-x64.zip`, extract the folder, and run `MeetRec\MeetRec.exe`.
