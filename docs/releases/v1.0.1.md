# MeetRec 1.0.1

MeetRec 1.0.1 adds a discard path for accidental or unwanted in-progress recordings.

## Highlights

- Added **Cancel This Recording** directly below **Stop Recording** in the shared tray and floating timer context menu.
- Cancelling requires confirmation before discarding the current recording.
- Confirmed cancellations stop capture, clean up temporary audio files, skip post-processing, and save no output file.
- Windows executable metadata now reports `FileVersion` `1.0.1.0` and `ProductVersion` `1.0.1`.

## Artifact

Download `MeetRec-1.0.1-win-x64.zip`, extract the folder, and run `MeetRec\MeetRec.exe`.
